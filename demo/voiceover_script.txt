What if your health data never left a sealed box — not even the AI could read it raw?

That's T3 MedAgent.

A privacy-preserving AI health navigator, built entirely on the Terminal 3 SDK.

Patient symptoms are analyzed inside a Trusted Execution Environment — the TEE. Not on a server. Not in the cloud. Inside cryptographically sealed hardware that not even the operator can inspect.

This is how we built it.

Every patient onboards through a real T3 identity flow. The agent calls otpRequest — Terminal 3 sends a live verification email. The patient enters the code. otpVerify runs. A DID is minted on the T3 network. A private encrypted map is created per patient using maps dot create. The profile is submitted via submitUserInput. That's five SDK primitives — in one onboarding flow.

This is the actual T3 network email that arrived during testing. Not mocked. Not simulated. Real.

The dashboard is where the TEE comes alive. The patient describes their symptoms. The agent calls contracts dot execute — a compiled Rust WASM binary runs inside the T3 TEE node. Risk level is assessed. Hospital booking is triggered automatically for high or critical cases. All of this happens without the server ever seeing the raw symptom text.

On the right — the Agent DID, live session status, TEE ready, and the SDK coverage tracker. Nine of sixteen primitives active in this single session.

Every execution is permanently logged. The audit trail calls contracts dot logs — immutable, on-chain, with tee underscore verified true on every entry. No delete. No edit. Full transparency.

T3 MedAgent also implements full delegation credentials. The agent issues a verifiable credential authorizing specific health functions — built using buildDelegationCredential, canonicalised, signed with signCredential, and the invocation preimage signed with signAgentInvocation. The complete VC signing pipeline.

Finally — TEE attestation verification. The app calls fetchDkgAttestation and verifyDkgAttestation to prove the T3 node is running genuine Trusted Execution hardware. This isn't a checkbox. This is cryptographic proof.

Seventeen SDK primitives. One complete application.
